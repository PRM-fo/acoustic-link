      The studio

      Both sides of SoundDrop, live on this page. Beam from the sender and the receiver listens through the microphone. Use one device, or open this page on two and keep them 15 to 50 cm apart.

      Sender

      Pick a file or type a message, then press Beam Sound.

      Receiver

      Press Start Listening and allow the microphone.

      How we can
      improve it further

      The studio works today. These are the upgrades that would make it ready for disaster zones and rescue missions.

      Reliability

      Error correction

      Stronger checksums so a loud terminal or a storm does not corrupt a message.

      Reach

      Phone-to-phone relay

      Receivers re-broadcast what they heard, so one speaker can cover a whole concourse or town.

      Trust

      Signed alerts

      Only verified authorities can send warnings, so a fake broadcast is rejected.

      Comfort

      Near-silent mode

      Ultrasonic transmission for places where an audible tone would disturb people.

      Access

      Languages and accessibility

      Auto-translated alerts, large text, vibration and screen-reader support.

      Integration

      Airport and alert systems

      Feed flight data and public-warning feeds straight into the broadcast.
